## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/OracleLoom.git`
2. `cd OracleLoom`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure OracleLoom, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
